# UX Research Synthesis

Build product definitions from approved evidence rather than plausible assumptions.

## Required approach

- Use only evidence approved at HG-01; keep assumptions visibly marked.
- Code observations, cluster themes, record contradictory evidence, and retain source references.
- Express needs and pain points without prescribing a solution prematurely.
- Create personas only when meaningful behavioral patterns exist; otherwise use proto-personas and label them clearly.
- Ensure empathy-map statements are supported by evidence.
- Refine the problem statement and hypotheses with confidence levels.

## Deliverable contract

Return themes, user needs, evidence-linked persona or proto-persona, empathy map, prioritized pain points, and refined problem statement. Label it `DRAFT — REQUIRES HG-02 APPROVAL`.
