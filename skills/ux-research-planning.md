# UX Research Planning

Plan research that resolves the highest-risk assumptions in the BRD.

## Required approach

1. Read the current BRD and list facts, assumptions, hypotheses, and unknowns separately.
2. Convert priority unknowns into neutral research questions.
3. Define participant criteria, recruitment constraints, method, sample rationale, consent, privacy handling, and analysis plan.
4. Write non-leading interview questions and realistic task prompts.
5. Define what evidence would support, weaken, or leave each hypothesis unresolved.

## Constraints

- Never present synthetic responses, desk research, or stakeholder opinions as user research.
- Minimize collection of personal and financial data; redact sensitive details from notes.
- State limitations, recruitment bias, and confidence.
- Treat the linked case study as reference material, not proof of current user needs.

## Deliverable contract

Return a research plan, interview guide, participant profile, consent/data-handling notes, and assumption register. Label the result `DRAFT — REQUIRES HG-01 APPROVAL`.
