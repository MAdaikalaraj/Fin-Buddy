# Information Architecture

Turn approved user needs and MVP scope into understandable structures and flows.

## Required approach

- Inventory content, functions, data dependencies, and entry points.
- Define hierarchy and labels in user language.
- Map happy paths plus permission denial, missing data, stale data, ambiguity, calculation failure, unsafe advice, correction, support, and exit paths.
- Show where deterministic services provide financial numbers and where AI provides explanation.
- Keep automated payments, investing, and other out-of-scope actions outside the MVP flow.

## Deliverable contract

Return a sitemap or navigation model, task flows, conversation flow, state inventory, and rationale. Label it `DRAFT — REQUIRES HG-03 APPROVAL`.
