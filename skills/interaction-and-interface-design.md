# Interaction and Interface Design

Create an understandable, trustworthy assistant experience from HG-03-approved architecture.

## Sequence

1. Produce annotated low-fidelity wireframes covering the state inventory.
2. Pause for the wireframe checkpoint within HG-04 before high-fidelity work.
3. After approval, define visual hierarchy, content, components, responsive behavior, and prototype interactions.

## Non-negotiable states

Include consent, loading, source period, assumptions, transaction evidence, uncertainty, missing data, correction, feedback, opt-out, deletion/permission management, and support escalation where relevant.

## Quality bar

- Do not imply guaranteed financial outcomes.
- Make calculations and source records inspectable.
- Meet the team's selected accessibility target and document unresolved risks.
- Use plain language and preserve user control.

## Deliverable contract

Return annotated wireframes first, then approved high-fidelity specifications and prototype coverage. Label all artifacts `DRAFT — REQUIRES HG-04 APPROVAL` until the gate is signed.
