# Journey and Service Mapping

Describe the user's end-to-end experience and the system responsibilities behind it.

## Required approach

- Define the actor, scenario, starting condition, goal, and journey boundary.
- Map stages, actions, questions, touchpoints, emotions, pain points, evidence, and opportunities.
- For future-state journeys, identify consent, data retrieval, deterministic calculation, AI explanation, correction, feedback, and escalation.
- Distinguish visible user experience from backstage product, data, AI, security, and support responsibilities.
- Identify moments where trust can be gained or lost.

## Deliverable contract

Return current-state and/or future-state journeys with evidence references, gaps, opportunities, and ownership. Label it `DRAFT — REQUIRES HG-02 APPROVAL`.
